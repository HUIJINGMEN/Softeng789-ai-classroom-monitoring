## 화면 변경

1. **학생 홈·출석**: 오늘 수업과 저장된 출석 상태를 우선 표시합니다. 날짜는 Auckland 기준입니다. 인접 날짜 수업과 기존 학습 기록·업데이트는 펼쳐서 확인합니다. `Open camera & activity`와 `Full schedule`을 홈 상단에 배치하고, `Camera & activity`를 데스크톱 상단 메뉴와 모바일 하단의 독립 탭으로 추가했습니다. 사진 출석 동의·철회 관리는 `Profile`로 이동했고, 등록이 필요한 경우에만 홈에 안내합니다. 사진 출석 기능이 비활성인 경우에도 일정과 수동 출석 안내를 표시합니다.
2. **카메라**: 별도 화면에서 미리보기·시작/정지·로컬 동의·두 공유 스위치·공유 상태를 표시합니다. 현재 얼굴 감지 상태·참조 설정 버튼·최근 관찰 기록은 기본으로 표시합니다. 상세 수치·설정 안내·Phase3D 실험만 접어 두었습니다. 카메라 정지 시 로컬 동의와 성인 확인도 초기화합니다. 화면을 나가면 카메라와 공유를 정리합니다.
3. **교사 목록**: 학생 목록을 기본 화면으로 표시합니다. 출석 상태와 관찰 공유 상태를 구분합니다. 학생 상세를 열면 관찰 요약과 해당 학생의 영상 보기 버튼을 표시하며, 상세를 닫으면 영상 수신을 해제합니다. 기존 검색·필터·20명 단위 페이지 이동·관찰 검토 기능을 유지합니다. 관찰 공유가 비활성인 환경에서도 사용할 수 있도록 `Shared videos only` 진입을 유지했습니다.

UI 문구는 영어입니다. 기존 학습 기록·결제·보고서 등의 화면은 유지합니다.

## 유지한 경계

- 사진 출석 요청과 교사의 실제 출석 저장을 구분합니다. 저장된 출석이 과거 요청 상태보다 우선합니다.
- 사진 제출 동의, 로컬 분석 동의, 관찰 공유 동의, 영상 공유 동의를 별도로 유지합니다.
- 관찰 공유 중지/삭제는 영상 공유를 중단하지 않고, 영상 공유 중지도 관찰 공유와 원본 카메라를 중단하지 않습니다.
- a13da49 시점의 UI 정리에서는 Phase3D 감지 알고리즘·임계값·워커·카메라 분석 코드를 변경하지 않았고, `LocalEyeHeadPanel.tsx`는 원본 그대로 외부 표시 영역만 접었습니다. 이후 리뷰 수정에서 `onEnabledChange` 상태 알림 콜백만 추가했습니다.
- Phase3D 결과를 교사에게 전송하거나 출석·집중도·졸음 점수로 연결하지 않았습니다.
- 영상 공유 한도는 최대 4명으로 유지합니다. 21명 목록 검증은 영상 동시 부하 검증이 아닙니다.
- 백엔드·Python 서비스·DB 스키마는 변경하지 않았습니다. 사용자 얼굴·출석 데이터를 초기화하거나 수정하지 않았습니다.
