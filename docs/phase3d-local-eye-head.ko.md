# Phase 3D — 로컬 눈 감김·고개 숙임 관찰

현재 카메라에서 **양쪽 눈 감김과 고개 숙임의 지속 시간**을 관찰하는 성인 자원자용 실험 기능입니다. 졸음·수면·피로·집중도·감정을 판정하거나 출석을 변경하지 않습니다. 새 관찰 결과는 교사에게 전송되지 않습니다.

## 실행 방법

기존 서버 시작·종료 명령을 그대로 사용합니다. 기존 MediaPipe 모델이 설치되어 있으면 모델 추가 다운로드나 DB 변경이 필요하지 않습니다.

1. 학생 로그인 후 데스크톱 상단 메뉴 또는 모바일 하단 탭의 **Camera & activity**를 엽니다(또는 Home → **Open camera & activity**).
2. **01 Camera & detection**에서 성인 확인·로컬 분석 동의 → 공유할 경우 수업 선택 → **Start camera**. 관찰·영상의 독립 공유 스위치는 **03 Share with your teacher**에 있습니다.
3. **04 Experimental tools**를 펼쳐 **Enable local eye and head observations**를 켭니다. 접힌 summary에도 **On / Off**가 표시됩니다. 기본값은 꺼짐이며 두 번째 카메라를 요청하지 않습니다.
4. **Calibrate open eyes and head**를 누르고, 양쪽 눈을 자연스럽게 뜬 채 정면을 2초간 바라보세요. 최소 8개의 안정적인 샘플이 필요합니다. 눈을 감거나 자세가 크게 변하면 보정 시간이 다시 시작됩니다. 기존 **Set forward reference**와 별도 기준입니다.
5. 짧게 깜빡여 보세요. 이력에는 기록되지 않아야 합니다. 양쪽 눈을 2초 이상 감으면 **Eye closure**에 시간이 표시되고 **Sustained eye closure observed**가 이력에 한 번 추가됩니다. 한쪽 눈만 감거나 애매하면 **Not measurable**로 처리합니다.
6. 정면으로 돌아온 뒤 고개를 약간 숙여 보세요. 기준보다 아래로 15° 이상 숙인 상태가 3초 이어지면 **Sustained lowered head observed**가 표시됩니다. 위를 보는 동작은 고개 숙임에 포함하지 않습니다. 현재 두 항목 모두 눈 좌표와 조명 검사를 통과해야 하므로, 눈 측정이 실패하면 고개 방향 값이 있어도 고개 숙임 측정이 함께 중단될 수 있습니다.
7. 어두운 환경·얼굴 가림·큰 옆돌림·여러 얼굴도 확인하세요. 감지된 품질 문제와 분석 끊김은 타이머를 초기화합니다. 모든 가림을 알아내는 기능은 아니므로 잘못된 결과가 나오면 테스트 사례로 기록하세요.
8. 창/탭을 전환했다 돌아오세요. 카메라는 유지하되 숨김 상태나 샘플 중단 시간을 지속 시간에 더하지 않아야 합니다.
9. 기존 이벤트 공유와 영상 공유를 함께 켤 수 있습니다. 기존 얼굴 미검출·고개 움직임 이벤트는 종전대로 공유되지만 **이번 눈 감김·고개 숙임 상세 결과와 이력은 공유하지 않습니다**. 영상 공유를 켠 경우 교사는 영상 속 얼굴·자세를 볼 수 있습니다.
10. 실험만 끄면 기준과 이력이 삭제되고 기존 분석·공유는 유지됩니다. **Stop camera**, 동의 철회 또는 카메라 화면 이탈은 전체 카메라를 종료하고, 두 공유 스위치와 성인 확인·로컬 분석 동의도 해제합니다. 다시 시작하면 실험은 꺼짐이며 재보정이 필요합니다.

## 표시되는 정보

- **Not measurable:** 판독 불가. 가림·각도·조명·여러 얼굴·불확실한 눈 모양 등을 조정하세요. 불참이나 불집중이라는 뜻이 아닙니다.
- **Not observed:** 현재 해당 동작이 관찰되지 않음.
- **Measuring duration:** 아직 지속 시간 기준에 도달하지 않음.
- **Sustained observation:** 실험용 시간 기준에 도달함. 졸음 판정이 아닙니다.
- 이력은 최근 20개만 페이지 메모리에 유지합니다. 눈 감김·고개 숙임을 합친 점수는 없습니다. **Clear local eye/head history**는 이력만, 재보정은 기준과 이력을 초기화합니다.

## 한계 및 검증

눈 감김 2초·고개 숙임 3초는 초기 실험 설정이며 검증된 졸음 기준이 아닙니다. 안경 반사·눈꺼풀 모양·피부에 비치는 조명·카메라 각도·부분 가림 때문에 오탐이 날 수 있습니다. 보정이 안 되는 경우를 눈 감김으로 간주하지 않습니다. 사람이나 카메라 위치를 바꿨다면 재보정하세요.

실제 얼굴 정확도는 아직 측정하지 않았습니다. 여러 성인 자원자와 조명·안경 조건에서 실제 눈/고개 동작을 기록하고, 오탐 횟수·누락·판독 불가 시간·보정 성공률을 측정해야 합니다. 개인 테스트로 모델 전체 정확도를 주장할 수 없습니다. 수면·피로·집중도 자동 추론으로 확장하려면 최초 요구사항에 따라 배포 환경의 법적 허용 여부와 별도 검증을 먼저 확인해야 합니다.

파일 구성·세부 임계값·검증 기준은 [영문 구현 가이드](phase3d-local-eye-head.md)를 참고하세요.

## 이번 검증 결과

### 현재 범위 마무리 및 사용자 실제 테스트

Phase3D는 **로컬 실험 기능** 범위에서 마무리하고 감지 기능의 추가 개선은 보류합니다. 운영 수준의 정확도 검증을 마쳤다는 뜻은 아닙니다.

- 사용자는 안경을 벗으면 눈 감김이 작동하고, 안경 착용 시에는 **Not measurable**과 **Not observed**가 반복된다고 보고했습니다. 빛 반사는 추정 원인이며 확정하지 않았습니다.
- 고개 숙임은 작동했지만 필기 중에도 감지됐습니다. 자세 감지 결과로 볼 수 있지만 졸음의 증거로 해석할 수 없습니다.
- 한 명의 정성적인 테스트 결과이며, 정답 구간을 기록한 정확도·누락률 검증은 아닙니다. 안경 사용자에게 안경을 벗도록 요구하는 방식으로 해결하지 않습니다.
- 졸음·집중도 판정, 통합 점수, 출석 변경, 새 교사 알림은 추가하지 않습니다. Phase3D 상세 결과는 로컬에 유지합니다.

향후 안경 조건의 안정성, 눈과 고개 측정의 품질 조건 분리, 측정 가능 여부의 명확한 표시를 별도 범위로 검토할 수 있습니다. 지금은 Phase2 변경 사항 통합과 별도 Phase2·3 화면 정리가 다음 작업입니다.

2026-10-26 기준 프론트엔드 **388개 테스트와 빌드**를 통과했습니다. 새 관찰 기능 전용 테스트는 12개입니다. 실제 MediaPipe 워커 로딩과 WebRTC 연결을 확인했고, 재현 가능한 모의 얼굴 좌표로 보정·눈 감김·고개 방향·조명 실패·탭 숨김·초기화 동작을 검증했습니다. 실제 얼굴 정확도를 검증한 것은 아닙니다.

기존 고개 움직임 이벤트는 정상 전송되면서 새 눈/고개 상세 결과는 API 요청에 포함되지 않는 것을 확인했습니다. 모바일 너비 390px에서 가로 넘침과 페이지 오류가 없었고, 임시 계정·수업을 정리했습니다. 백엔드 코드·DB는 변경하지 않아 백엔드 테스트는 이번에 재실행하지 않았습니다.

최대 초당 5회 관찰하므로 프레임 사이의 짧은 깜빡임은 놓칠 수 있습니다. 표시 시간은 연속해서 관찰된 샘플 기준이며, 실제 눈 깜빡임 빈도를 정확히 측정하는 기능은 아닙니다.
